# Dice Game App

A simple Flutter dice game application.

## How the Game Works

The player rolls two dice.

- If the total is 10 or more, a happy image is displayed.
- If the total is less than 10, a sad image is displayed.
- The Reset button returns both dice to 1.

## Features

- Roll two dice
- Calculate the total
- Display a happy or sad image
- Reset the game
- Responsive layout
- Dark theme

## How to Run

1. Clone or download the project.
2. Open the project in Android Studio or VS Code.
3. Run:

```bash
flutter pub get
```
```bash
flutter run
```
